
# Bike Sharing Analytics Dashboard

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis pola penyewaan sepeda
menggunakan Bike Sharing Dataset periode 2011–2012.

Analisis berfokus pada pola penyewaan berdasarkan jam,
perbedaan hari kerja dan non-kerja, musim, serta kondisi cuaca.

## Library yang Digunakan
- Pandas
- Streamlit
- Plotly

## Cara Menjalankan Dashboard

1. Pastikan Python sudah terinstal.
2. Buka terminal atau Command Prompt pada folder proyek.
3. Instal library dengan perintah:

   pip install -r requirements.txt

4. Jalankan dashboard dengan perintah:

   streamlit run dashboard/dashboard.py

5. Dashboard akan terbuka melalui browser.

## Dataset
Bike Sharing Dataset (2011–2012).

## Analisis
Dashboard menyajikan:
- Pola penyewaan sepeda berdasarkan jam.
- Perbandingan hari kerja dan non-kerja.
- Rata-rata penyewaan berdasarkan musim.
- Rata-rata penyewaan berdasarkan kondisi cuaca.
